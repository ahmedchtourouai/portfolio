# AI Engineer Portfolio (Next.js + 3D + Framer Motion)

This is a frontend-only portfolio demo built with Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion and @react-three/fiber.

Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000

Public website: https://ahmedchtourouai.github.io/portfolio/

Notes
- The contact form sends messages to `ahmedchtourou.ai@gmail.com` through FormSubmit. The first live submission may require email confirmation from FormSubmit.
